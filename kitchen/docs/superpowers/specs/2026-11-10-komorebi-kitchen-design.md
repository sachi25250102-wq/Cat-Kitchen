# 小满食堂：单机烹饪游戏设计

## 目标

制作可直接打开的中文离线单机游戏。借鉴 Cook or Cooked 的像素厨房氛围、方向键切菜、时间管理和动物捣乱，使用原创名称、场景、角色、菜谱和代码。

## 实现选择

采用原生 HTML、CSS、Canvas 和 JavaScript，无构建步骤、运行时依赖、账号或服务器。用户没有指定引擎；这是为了让 Windows 上双击 index.html 即可玩的实现选择。Godot 便于后续原生导出，但需要额外编辑器；联网框架不符合本次单机目标。

## 游戏流程

主菜单 → 第一天开店 → 接单、切菜、控火、出餐 → 营业结算与升级 → 第二天 → 第三天 → 最终评分。另有无计时练习模式。一次营业 90 秒，暂停和失焦冻结所有计时。三个营业日逐渐增加菜谱与订单压力。结算可重新挑战；所有解锁只在本地保存。

玩家点击订单或按 1、2、3 选择订单，按方向键或 WASD 完成显示的切菜序列，进入控火后在绿色区间按空格完成料理，再按空格出餐。错误输入降低连击并扣分，但不软锁；过火退回重做。鼠标和触屏按钮提供同等操作。

定期出现偷食小动物，按 F 或点击动物驱赶。它停留五秒后降低订单耐心。练习模式不生成捣乱事件，不扣营业时间。菜单、帮助、暂停、声音、重试均提供可见反馈。

## 美术与布局

原创日式街边食堂，窗外樱花与黄昏，木制柜台、红色暖帘、釉色餐具。主角是围围裙的小猫。限定色调：深咖 #382c2a、木棕 #976544、米白 #fff1d2、暖红 #c55743、鼠尾草绿 #73977a、夕照金 #f1ba67。像素插画背景与 Canvas 动态角色、蒸汽、食物、碎屑分层。中文使用系统圆体/黑体栈，标题使用衬线中文字体栈；不依赖在线字体。

桌面以厨房舞台为主体，右侧是纸质订单夹。下方显示当前动作和键位。移动端纵向排列，可见触摸控制。尊重减少动态效果偏好。图像和音频全部本地加载；音效由 Web Audio 合成。

## 数据与验证

逻辑独立于 DOM、Canvas、时钟和音频，通过注入随机函数做确定性测试。验证订单成功路径、误按、过火、超时、暂停、捣乱、升级限制、练习模式和三天通关。浏览器验证菜单、键盘和触摸入口、响应式、声音、暂停、结算、重新开始以及控制台错误。存储损坏或禁用时仍可玩。
